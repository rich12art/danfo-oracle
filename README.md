# Danfo Oracle

Playable Lagos corridor runner. Open `index.html` or the deployed URL.

Steer with arrows, A/D, swipe, or the pads. Open the phone to slow time and read Route Oracle, Pothole Ear, Cabin Sense, or Street Radio. Brake in the right lane at a stop to collect fares.

Progress, garage upgrades, and the motor park board save in this browser.
